# 祖龙三端安装与诊断指南

适用平台：Windows、Linux、macOS。

## Windows

```powershell
.\scripts\setup_windows.ps1
```

如只想跑诊断，不安装依赖：

```powershell
.\scripts\setup_windows.ps1 -SkipInstall
```

## Linux

```bash
bash scripts/setup_linux.sh
```

Linux 音频依赖通常需要先安装 PortAudio/ALSA/Pulse/PipeWire 开发包。

## macOS

```bash
bash scripts/setup_macos.sh
```

macOS 默认不安装 `onnxruntime-gpu` 和 `bitsandbytes`。ASR 主路径 SenseVoice 使用 CPU，Whisper 可在 PyTorch 支持时使用 MPS。

## 诊断命令

```bash
python scripts/doctor.py
python scripts/doctor_models.py
python scripts/doctor_audio.py
python scripts/doctor_camera.py --scan-range 3 --no-read
python -m pytest tests/platform -q
python scripts/smoke_platform.py
```

## 平台 Profile

默认自动识别平台，也可强制指定：

```bash
ZULONG_PLATFORM_PROFILE=macos python scripts/doctor.py
```

Windows PowerShell:

```powershell
$env:ZULONG_PLATFORM_PROFILE="macos"; python scripts\doctor.py; Remove-Item Env:ZULONG_PLATFORM_PROFILE
```

## 仍需手动准备的资产

- Ollama 或云端 LLM。
- SenseVoice/Kokoro/YOLO/ALBERT/BGE 等模型权重。
- 可选 CosyVoice 代码和 prompt 音频。

缺少可选资产时，doctor 会给出 WARN；核心文本后端不应因此启动失败。
